# Project rules

These rules apply to every commit on this repository.

- Update `main` as the repository owner, `adeshsuryan`. Do not push commits under another author or a bot account.
- Every release commit on `main` gets an annotated tag `vX.Y.Z`. The tag, `package.json` `version`, `jsr.json` `version`, and `CHANGELOG.md` use that same number.
- Do not commit archives (`.zip`, `.tar`, `.tgz`, `.gz`).
- Do not commit tokens, `.env` files, private notes, or planning documents that live outside this repository.
- Do not add machine-attribution lines, generated banners, or tool signatures to source files.
- Keep instructions in this repository limited to how to run the tool and how the repository is maintained. Product planning stays off the remote.
